# hashmimic.com

Personal site of **Hashmimic** — an indie hacker and musician. A WebGL-driven Next.js
app featuring an interactive 3D hero, a dynamic on-chain portfolio, and per-route
Open Graph images.

🔗 <https://hashmimic.com>

## Tech stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router) + React 19
- **UI:** [HeroUI](https://www.heroui.com/), Tailwind CSS 4, Framer Motion
- **3D / WebGL:** [react-three-fiber](https://r3f.docs.pmnd.rs/), drei, postprocessing, three.js
- **Web3:** wagmi + viem + ethers (dynamic UnchainedX portfolio data)
- **Tooling:** pnpm, ESLint 9 (flat config), Prettier, Husky + lint-staged, Playwright

## Requirements

- **Node.js >= 24** (see `engines` in `package.json`)
- **pnpm** (package manager)

## Getting started

```bash
pnpm install
pnpm dev
```

Open <http://localhost:3000> in your browser.

For local environment variables, copy the example files and fill in the values:

```bash
cp .env.example .env.local
```

## Scripts

| Command | Description |
| --- | --- |
| `pnpm dev` | Start the dev server |
| `pnpm build` | Production build |
| `pnpm start` | Serve the production build |
| `pnpm lint` | Run ESLint |
| `pnpm prettier` | Format `src/` with Prettier |
| `pnpm fmt` | Format then lint |
| `pnpm build:og` | Build the app and generate per-route OG images |

## Project structure

```
src/
  app/                 # App Router routes
    (base)/            # Main layout group: home, music, portfolio, who
    api/               # Route handlers (e.g. portfolio-image)
  components/
    WebGL/             # react-three-fiber scenes, shells, shaders
  lib/                 # Renderer, responsive helpers, portfolio data
  providers/           # HeroUI and app providers
public/
  og/                  # Generated Open Graph images
scripts/
  build-og.mjs         # OG image generation
```

## Open Graph images

Per-route OG images live in `public/og/` and are generated by `scripts/build-og.mjs`.
Regenerate them with:

```bash
pnpm build:og
```

## Deployment

Deployed on [Vercel](https://vercel.com/). Pushes to `main` trigger an automatic
production deploy.
